T-Net v6.31.1 — SECURITY HOLD (11 November 2026)

The experimental TNet-OneClick-Repair-6.31.1.exe has been withdrawn from public download following a high-severity Microsoft Defender Settings Modifier detection reported during download.

Do not restore, allow, or execute any previously downloaded copy. This report has not been established as a false positive.

The experimental repair payload is also withdrawn. The stable T-Net update feed remains at v6.30.0.

The corrected v6.31.1 interface and update integration code remain under review on the design/approved-v631-final-controls branch. A future installer must pass malware/security review, Windows Defender scans, signature verification, backup/rollback and data-preservation testing before any public release.

No changes are required to a working local T-Net installation solely due to this release hold.
